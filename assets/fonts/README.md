# Bundled typography

Lato Web Regular (400) and Semibold (600), version **2.015; 2015-08-06**.
These unmodified files were copied offline from `C:\Windows\Fonts`.
The embedded name-table records 0, 5, 8, 9, 13 and 14 identify the version,
authors and SIL OFL 1.1 grant. No Windows system-font redistribution grant
is assumed. The OFL grant belongs to these particular files.

The local files are the pinned input; the upstream web site was not accessed.

Source Sans 3, the review's first choice, was not found locally. Lato is the
available independent OFL alternative; it is not a franchise-style substitute.
No fetch step is needed for the bundled font. A future switch to Source Sans 3
must supply actual Regular/Semibold binaries, their full copyright/OFL notice,
version and SHA-256 before changing launcher inputs. Do not invent hashes.

Load these privately for the process; never install them globally. Use system
UI fallback for unsupported glyphs, setup and system high contrast. Packaging
must keep OFL.txt with the fonts. Font integration belongs to A/C, outside B1.
