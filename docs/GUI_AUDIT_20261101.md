# GUI audit, 2026-11-01 (common/settings.h kKnobs, main 89dd500).

Status: approved and implemented (decisions 1-5 as proposed; `rt_emissive` is written by the emission level).
`fg_letterbox` has no automatic mode in the layer yet, so it is an ini-only key without an entry. Old ids map
through `kKnobAliases`, old files through `Choice::mark` (tests/settings_test.cpp `test_user_ini_migration`).

## User decisions needed
1. Water: one "RT water" choice with levels (Off / Reflections / + shadows / + refraction) instead of 8 entries? (proposed: yes)
2. Hit materials: one bundle "Hidden-surface shading" with levels, the foliage families automatic? (proposed: yes)
3. Remove "Current cascade sun shadows" and "Local light sampling (exact-k)" from the GUI (ini only)? (proposed: yes)
4. `rt_hit_emission` 1 or 2 (open in PROGRESS). Proposed level "hidden" (1) inside the bundle, "all" developer-only.
5. "Emission at ray hits" needs `rt_emissive=1`, which has no GUI entry and which data/release.ini forces to 0:
   a player cannot enable it. Add `rt_emissive` to the bundle's requirements (written by the bundle), or hide it.

## Main settings (not experimental): keep all
rr, rt_geometry, sun_shadows, gi, local_shadows, reflections, frame_generation, rt_intensity, fps_cap, reflex (advanced).
`exp_roof_shadows` (Roof sun shadows, `rt_cascade_casters`, live): qualified, on in Ultra since 10-31 (+0.3 to +1.3 ms).
Move it out of the Experimental id prefix into the main list (it already is not `experimental`).
