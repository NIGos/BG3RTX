## Traced gem (2026-11-04, replaces the split lantern)

The original mark is a six-facet gem in gold tones struck by a cream ray from the
upper left, answered by a three-stroke glint: light, a surface and its response.
Solid polygons only, no letters, glow or borrowed symbols. The 16-unit master is
pixel aligned for 16-24 px; 32 px and larger use the 64-unit master. Set plain
BG3RTX text beside it in the UI font. No Larian or Wizards of the Coast artwork,
marks, typefaces or visual references were used or imitated. Launcher icons are
inline 24-unit SVG strokes (1.75, round caps) in tools/launcher/ui/app.js.

## Palette and layout

| Role | Value |
|---|---|
| Background / raised panel | `#17191D` / `#22262C` |
| Main / secondary copy | `#F1E7D2` / `#BEB5A4` |
| Decorative border / candle accent | `#454B54` / `#D6AA62` |
| Focus / success | `#8BCBDD` / `#9BC6A4` |
| Warning / error | `#F2C078` / `#F1948A` |

Use an 8 logical-pixel spacing base, 16-pixel card padding, 24-pixel section
gaps and controls at least 32 pixels tall. Use thin separators and short angular
corner notches sparingly. The border token is decoration, not sufficient by
itself for a control boundary or focus indicator. Text panels remain flat;
texture and decoration never sit under small copy. See
`assets/branding/SURFACE_RECIPE.md` for the reproducible original surface.

Colour artwork is intended for charcoal. On light surfaces use the black mono
asset: parchment brackets/gold on parchment are visibly too faint. White is
for dark backgrounds. In system high contrast substitute the actual system
foreground for all SVG fills and omit texture, rather than assuming white.
Never convey a setting or warning solely by colour or the emblem.

## Typography and provenance

Use the bundled **Lato Web 2.015 (2015-08-06)** Regular 400 / Semibold 600 as
the available offline OFL alternative to the review's Source Sans 3, which was
not found in the checked checkout, external SDK filenames, Python environment
or Windows font inventory. Lato is independent UI typography, not a franchise
imitation. Files were copied unmodified from local `C:\Windows\Fonts`;
embedded copyright, version and licence records were inspected with fontTools.
`assets/fonts/README.md` records source, authors and reserved name. Full SIL
OFL 1.1 is in `assets/fonts/OFL.txt`; SHA-256 identities are pinned in
`assets/fonts/manifest.json`. No font was generated or fetched.

Use 11 pt body/control text, 16–20 pt headings, modest heading tracking. Load
privately, never register a system font. Use system UI fallback for missing
glyphs, setup and high contrast. A still needs to verify real control metrics,
keyboard focus, screen-reader names, contrast of all rendered text states,
720 logical-pixel reflow and 100/125/150/200% DPI. Assets alone do not pass UX QA.

## Offline reproduction and review

Run from any directory with **Python 3.11 + Pillow 12.3.0** already installed:

```powershell
python scripts/export-branding.py
python scripts/export-branding.py --check
```

No automatic installation or network access. The exporter runs BelowNormal on
Windows. Its narrow SVG reader accepts solid polygon children only and rejects
unsupported drawing elements/attributes. Keep masters within this vocabulary.
It rasterizes at 8x then uses BOX area reduction, with no ringing/glow. PNG
compression is fixed; `manifest.json` pins source/output SHA-256. `--check`
compares every generated byte and checks bundled font/licence hashes, all nine
ICO directory sizes and exact PNG-to-ICO RGBA round trips. Pillow's PNG/zlib
build can affect encoded bytes across environments; the committed manifest and
`--check` detect drift rather than silently accepting it. No timestamps enter
assets. ICO uses RGBA PNG frames for modern Windows, including 256 px.

Verified sizes: **16, 20, 24, 32, 40, 48, 64, 128, 256** in the ICO; additional
512 px documentation PNG. Two consecutive generations compare byte-identically.
`assets/branding/review-light-dark.png` was visually inspected at 16/32/48/256 px
on charcoal and parchment. Top rows show colour/black/white at actual size;
the bottom enlarges 16 px without interpolation. The aperture, separate beam
and offset bracket gaps remain distinct. Edges have transparent exterior and
no coloured matte/halo. Low-contrast opposite-colour examples intentionally
show why the correct mono variant must be selected. This is raster inspection,
not a claim of Windows taskbar or launcher DPI verification.

No renderer, ABI, setting, shader or installer changes; shader request delta 0.
Project artwork distribution still follows the project's pending licence choice.
